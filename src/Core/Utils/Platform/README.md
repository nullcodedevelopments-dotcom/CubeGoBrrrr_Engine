# Platform

This folder should contain platform abstraction helpers.

Getting started:
- add wrappers for window creation, input, and OS services
- keep platform-specific code isolated from renderer and scene logic
- support Linux first, and add Windows/macOS later if desired

Resources:
- [LearnOpenGL: Creating a Window](https://learnopengl.com/Getting-started/Creating-a-Window)
- [GLFW documentation](https://www.glfw.org/docs/latest/)
- Real-Time Rendering by Tomas Akenine-Möller et al.
